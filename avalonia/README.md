# かわったよ Avalonia 版（v0.2.5）

Windows 11 x64 用の別ビルドです。Native AOT の配布 ZIP を展開し、
`かわったよ.exe` を実行します。別途 .NET ランタイムや SQLite のインストールは不要です。
同梱 DLL は exe と同じ場所に残してください。監視対象の共有先ではなく、書き込めるローカルのフォルダに展開してください。

## v0.1.4 の設定を使用する

旧アプリを通知領域から完全に終了し、同じフォルダにある `settings.json` と
`cache.sqlite3`（存在する場合）を
Avalonia 版の展開先に**コピー**します。旧アプリや元のファイルは残してください。
新たに `settings.json.bak` は生成しません。既存のものは、メインの設定が読めない場合に限り復元に使います。
v0.1.3 以前の `cache.json` は読み込みません。実際の監視パスや履歴を含むため共有・公開しないでください。

## 操作

- 「未読」は未確認の変更のみ表示。フォルダは既定で折りたたまれます。クリックで選択、開閉ボタンで展開、ダブルクリックで関連アプリやエクスプローラーを開きます。
- 「設定…」で子ウィンドウを開きます。「監視対象」と「動作と表示」の2タブがあります。「監視対象」はファイル・フォルダを選択するか、エクスプローラーからドロップして追加します。対象数は最後に正常に取得した除外後のファイル数です。最終更新・状態・照会時間も確認できます。
- 右クリックから開く、確認済み、表示名、再帰監視、登録解除などを操作できます。登録解除しても実ファイルは削除しません。
- 「設定」で間隔、常駐、通知、再帰監視、除外、表示を変更できます。通知の表示は Windows の通知設定にも従います。
- 上部の「履歴」で別ウィンドウを開きます。「履歴」は変更種別やパスを検索できます。監視の比較データ、未読、履歴は SQLite、設定と監視先の登録は JSON に保存します。

未読一覧の下部には「すべて折りたたむ」と「詳細」があります。「詳細」を押すと選択項目のパス・検知時刻・確認済みの範囲を表示します。

## 開発と検証

Avalonia の画面・ビルド設定は `avalonia/`、
ファイル照会・SQLite・設定の実装は `src/` にあります。

開発側では Windows x64、.NET 10 SDK、Visual Studio の C++ デスクトップ開発ツールが必要です。
依存パッケージは NuGet.org から取得します。利用側に開発ツールは不要です。
ビルドと配布 ZIP 作成では、インストール済み SDK が要求する Native AOT パックを復元します。SDK ごとのロックは `avalonia/obj/packages.sdk.lock.json` に保存し、Git 管理の `packages.lock.json` は変更しません。

```powershell
.\tool\build.bat
```

`build.bat` は .NET SDK を直接呼び出し、PowerShell スクリプトを実行しません。実行ファイルと DLL は `bin` に出力します。配布 ZIP の作成は別の操作です。PowerShell スクリプトの実行が許可されている開発環境で `.\tool\package-avalonia.ps1` を実行してください。Visual Studio で開く場合は avalonia/Kawattayo.Avalonia.csproj を選んでください。ZIP の出力は `build/Kawattayo_v0.2.5_Avalonia_Windows_x64.zip` です。
`-p:KawattayoUseNls=true` は比較用。標準設定では Windows の ICU を使います。
NLS にしても Skia・HarfBuzz の DLL は不要にはなりません。

EXE 1 個で配るビルドは `tool\build-single.bat` を実行します。
成果物は `bin-single\Kawattayo.Avalonia.exe` です。通常の `bin` は上書きしません。
単体版は Native AOT ではなく、内蔵した DLL を起動時に一時フォルダへ展開します。

ローカル試験では日本語を含むパス、再帰照会、未読ツリー、履歴、SQLite 再読込を確認しています。
実際の複数 PC 間の SMB と、実機のマルチモニター DPI、通知バナー・エクスプローラーとのクリップボード動作は環境ごとに確認してください。
