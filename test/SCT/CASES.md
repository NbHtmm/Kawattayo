# 回帰試験ケース台帳

1行を独立した合否判定とする。配布版の自動試験はケースIDを `result.json` で参照できる。
「自動」は実装済み、「予定」は未実装、「要環境」は実機条件が必要。試験の最新合否は実行結果を参照し、この台帳の状態と混同しない。
優先度は P0（データ保護・誤検知・主要処理）、P1（主要操作と互換性）、P2（性能・端末条件）。領域ごとの既存UTと内部結合試験は [試験範囲一覧](../COVERAGE.md) を参照。

| ケースID | 優先 | 前提・操作 | 合格条件 | 状態 |
|---|---|---|---|---|
| SCT-CLI-001 | P0 | 基準後に1文書を更新し収集、保存先の同名ファイルを変えて再収集 | 更新元を変えずコピーする。再収集は上書きせず終了コード3 | 自動 |
| SCT-CLI-002 | P0 | ローカルの監視元を一時退避し差分と収集を実行、復旧後に更新 | 閉塞中は削除0・確認不能、保存0件。復旧後は実際の更新だけ | 自動 |
| SCT-CLI-003 | P0 | 追加・更新・削除を同時に作り、保存先に同名成果物を置く | 3種を正しく分類。既存成果物を保護し追加分は保存、削除はコピーしない | 自動 |
| SCT-CLI-004 | P1 | 再帰オフ＆除外複数、直下・下位・除外対象へ追加 | 対象に合う直下ファイルだけを検知 | 自動 |
| SCT-CLI-005 | P1 | 同名2件を作り、一覧、名前、不足引数、存在しないID、正しいIDで照会 | ID一覧・エラー分類・空のJSONが契約に一致 | 自動 |
| SCT-CLI-006 | P0 | 保存先に監視元自身・監視元配下を指定 | 両方を拒否、出力を作らず元ファイルを保持 | 自動 |

| SCT-GUI-004 | P0 | 個別ファイルを更新・削除・再作成し、各回照会 | 各変化が1度だけ記録され、未変更の再照会では増えない | 自動 |
| SCT-GUI-005 | P0 | フォルダを退避して照会後、戻して1件だけ更新 | 一時不達で削除扱いせず、復旧後は変更のみ検知 | 自動 |
| SCT-GUI-006 | P0 | 未読2件を一括取得。保存先の片方を事前作成 | 相対階層保持、既存ファイルは不変、成功と失敗を区別 | 自動 |
| SCT-GUI-007 | P0 | 「ダウンロードして開く」で試験用の関連アプリを使用 | 共有元ではなくローカルコピーが渡る | 予定 |
| SCT-GUI-008 | P0 | 差分プレビュー後に元ファイルを再更新 | 古い差分としてそのまま保存せず、元や既存出力も変更しない | 自動 |
| SCT-GUI-009 | P1 | ファイルとフォルダを選択／ドロップし、同一パスを再登録 | 正しい種類で1件ずつ登録、多重登録されない | 予定 |
| SCT-GUI-010 | P1 | 再帰をオン／オフに変更後に下位だけ更新 | 設定に従う。設定変更だけで既存ファイルを誤通知しない | 自動 |

| SCT-GUI-014 | P1 | 登録名・監視周期・文字サイズを変更して再起動 | 設定に従う。既存の監視対象・履歴を失わない | 予定 |
| SCT-PERSIST-001 | P0 | 設定破損、バックアップあり／なしを別環境で起動 | ありは復旧、なしは元データの破棄をしない | 自動 |
| SCT-PERSIST-002 | P0 | 起動時にSQLiteが破損・一時ロックされた別々の環境を試す | 起動を拒否して報告し、破損データを上書きしない。ロック解除後に未読を復元する | 自動 |

| SCT-HOOK-001 | P0 | 日本語と空白のある対象を更新して試験用EXEを実行 | 設定したコマンドが絶対パスを1引数で受け取る | 予定 |
| SCT-HOOK-002 | P0 | 除外・削除・一時不達、連続更新、フック失敗 | 対象外は未発火。連続更新や実行失敗の扱いが設定と仕様に一致 | 予定 |

| SCT-SMB-001 | P0 | Aから専用SMBを切断し、Bで更新して接続を戻す | 切断を削除扱いせず、復旧後にBの更新を検知 | 要環境 |
| SCT-SMB-002 | P0 | Aが監視中、Bが書き込み・改名・削除する | 監視がBの操作を妨げず、到達可能な正しい結果が出る | 要環境 |
| SCT-SMB-003 | P1 | UNC・権限不足・日本語・長いパスで照会する | エラーと消失を区別し、対応範囲内のパスを扱える | 要環境 |
| SCT-PERF-001 | P2 | 大量ファイルを監視し、照会中に画面操作や中止を行う | 事前に定めた目標時間内で応答し、データ欠落なし | 要環境 |
| SCT-DPI-001 | P2 | 4Kと倍率の異なる画面を使い、移動・縮小・文字サイズ変更 | ファイル名と操作を表示し、クリック領域がずれない | 要環境 |

機能を変更するときは、台帳のケースIDと期待結果を先に確認する。まだIDがなければ同じ変更で追加する。1ケースの合格で別領域を合格扱いしない。特にローカルのフォルダ退避は実SMB試験の代わりではない。
