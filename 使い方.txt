かわったよ v0.1.4 | Windows・C#版

【起動】
v0.1.4 は設定とキャッシュの保存形式が変わりました。旧版とは別のフォルダに展開し、監視先を再登録してください。旧版の履歴・未読は自動移行しません。
配布 ZIP を展開し、「かわったよ.exe」をダブルクリックします。メイン画面のタイトルバーでバージョンを確認できます。
Windows x64 用で、.NET Desktop Runtime を圧縮して同梱しているため、事前インストールは不要です。
起動時は一部の部品がユーザーの一時フォルダに展開されます。

【ソースからビルド（Windows x64）】
tool\build.bat を実行します。完成品は bin\かわったよ.exe です。旧 dist フォルダは更新されません。
以前の bin\Release\App や App.zip は新しいビルドでは更新されません。配布には使わないでください。
開発PCには .NET 10 SDK と win-x64 単体配布に必要なランタイムパック等を事前に用意してください。
バッチはローカルの SDK とパッケージのみ使用します。不足時はダウンロードせずエラー終了します。
PowerShell・CMake・Ninja は不要です。利用者のPCには .NET のインストールは不要です。

【配布 ZIP の作成】
Windows の PowerShell で .\tool\package.ps1 を実行すると、build\Kawattayo_win_x64.zip ができます。
再配布するときは、使い方とライセンス・通知文書を含むこの ZIP を渡してください。設定や履歴は ZIP に入りません。

【使い方】
「設定…」を開き、「監視対象」でファイル・フォルダの登録と管理を行います。
「動作と表示」では監視間隔・常駐・既読・通知・文字サイズ・ダークモード・除外ルールを設定できます。
「ダークモード」で、メイン画面・設定・履歴の配色をすぐに切り替えられます。
初期値はライトで、選択は再起動後も維持されます。Windows のハイコントラスト配色は優先されます。
1. 「設定…」→「監視対象」の一覧の上にある「＋ 追加 ▾」ボタンで対象の種類を選びます。
   「フォルダを選択…」は Windows のフォルダ選択画面です。対象を選び「フォルダーの選択」で確定します。
   アドレスバーにローカル／共有パスを入力して Enter で移動し、そのフォルダを確定することもできます。
   「ファイルを選択…」ではファイルを選ぶか、「ファイル名」にフルパスを入力して「開く」を押します。エクスプローラーから
   「監視対象」タブの一覧にファイルとフォルダをドラッグして登録できます。「動作と表示」タブでは登録しません。移動・コピーはしません。
   「動作と表示」→「監視」で再帰監視のデフォルトを変更できます。初期値はオンです。「監視対象」の再帰監視列が「デフォルト」のフォルダに適用されます。
   個別に指定するには設定画面のフォルダを右クリックし、オン・オフ・デフォルトに戻す、のいずれかを選びます。ファイルには適用されません。
   範囲変更後の最初の一覧は新しい比較基準になります。右クリックの「登録解除」は監視登録のみ解除し、実ファイルは削除しません。
2. 「監視間隔（秒）」を設定します。初期値60秒、5～86400秒。
   「サーバー負荷を抑える」は初期値オンです。通常は次の巡回で通知のあったパスだけを確認します。フォルダの移動などは該当する配下も確認します。
   初回・手動更新・監視再開・再接続・通知欠落の検出時は登録範囲を取り直します。通知が使えない対象や購読上限（32）を超えた対象は毎回照会します。
   通常のフォルダは親の直下の名前変更も監視し、登録フォルダの改名・同名での作り直しを検出すると通知を張り直します。親の監視も購読枠を1つ使用し、必要な親を監視できない場合は毎回照会します。
   設定の「監視対象」に通知の利用状況と照会時間を表示します。「照会を中断」で監視を一時停止し、未完了の一覧を破棄します。通信応答待ちでは中断が反映されるまで時間がかかる場合があります。「監視を再開」で取り直します。
3. 「対象ファイル数」は、最後に正常に照会した、除外後の実ファイル数です。空のフォルダ・消失した単独ファイル・除外中の単独ファイルは 0、まだ一覧を取得していない場合は — です。
   状態列に「正常」「監視失敗」「未照会」「対象なし」を表示します。失敗理由は行のヒントで確認できます。
   Git リポジトリも通常のフォルダとして監視するため、.git 内のファイルも再帰監視の対象です。大規模なリポジトリは、必要なサブフォルダごとの登録も検討してください。
4. 監視対象一覧はクリックで選択、ダブルクリックで開きます。右クリックで開く、親フォルダを開く（ファイルのみ）、
   表示名の変更、確認済み、登録解除ができます。表示名は最初はファイル・フォルダ名です。空欄にすると元の名前に戻ります。
   表示名を変えても実際のファイル名や監視先は変更しません。F2 でも変更できます。
5. 未読行の右端の「確認済み」、右クリックの「確認済みにする」、または行を選んで Space で、対象を開かず確認済みにできます。
6. 「設定…」の「通知領域に常駐」で切り替えられます。オンでは ×・最小化で常駐し、
   通知領域から画面を戻したり完全終了したりできます。オフでは × で終了します。
   オフで最小化した場合はタスクバーに残り、監視は続きます。自動起動は登録しません。

【文字サイズと並び替え】
「動作と表示」→「表示」で9〜22ptから選べます。未読一覧のファイル・フォルダアイコンと開閉マークも文字サイズに連動します。
小さい画面では、未読一覧は名前を優先して表示し、長い名前の全体はヒントや詳細で確認できます。設定一覧の右側の列は横スクロールで確認できます。
「最前面」はメイン画面をほかのウィンドウの手前に固定します。もう一度押すと解除します。
未読一覧には「すべて展開」「すべて折りたたむ」があります。Ctrl＋クリックで個別選択、Shift＋クリックで範囲選択します。
右クリックの「パスをコピー」は選択したパスを改行区切りの文字列としてコピーします。「コピー」とは別の操作です。
選択した行をまとめて確認済みにできます。「コピー」は選択した複数のファイル・フォルダをまとめて Explorer に貼り付けられる形式でコピーします。
新規利用時には、削除通知と「開いたら既読」はオフ、Office のロックファイル（~$*）は除外対象です。通常の Office 文書は除外しません。
「動作と表示」で、登録フォルダ自身の更新日時も監視するかを選べます（既定はオフ）。自身のキャッシュを保存するフォルダの日時は監視しません。
「ファイルの削除（消失）を通知」をオフにすると、以後の消失は未読や履歴に追加されません。再出現は引き続き検知します。
「消失通知を消す」は未読一覧に消失の行がある場合のみ表示され、その行だけを取り除きます。実ファイル・監視登録・履歴は削除しません。
未読一覧・監視対象一覧・履歴の列見出しをクリックすると並び替え、同じ列をもう一度クリックすると昇順・降順を切り替えます。
未読一覧では親子関係を保ち、同じ階層の中で並び替えます。

【除外するファイル】
「動作と表示」→「除外するファイル」に、除外したいファイル名を1行に1つ入力して「除外ルールを適用」を押します。
「Officeの一時ファイルを追加」を押すと、編集中のロックファイル名に対応する ~$* が追加されます。
他の一時ファイルも除外する場合は、*.tmp などのルールを追加してください。* と ? が使えます。
パスではなく名前に対して判定し、フォルダの配下と個別に登録したファイルの両方に適用します。
ルールで対象外にしたファイルの未読は消えますが、既存の履歴や実ファイルは消えません。

【再起動時】
設定（監視先の登録・監視間隔・通知・表示など）は、exe 横の settings.json にだけ保存します。
照会で見つかったファイル名・前回の比較情報・未読/既読・履歴は、同じ場所の cache.sqlite3 に保存します。
旧版の cache.json は読み込みません。設定を持ち運ぶ場合は、アプリを完全終了してから settings.json と
settings.json.bak（あれば）および cache.sqlite3（あれば）をコピーしてください。実パスを含むため公開しないでください。
各ユーザーが書き込める、監視対象外の専用フォルダに exe を置いてください。
アプリを起動し直すと保存状態に戻り、最後の記録と比較します。起動していなかった間の
最終的な状態の違いは検出できますが、その間に起きて元に戻った変更までは検出できません。

【共有フォルダへの影響】
定期照会ではファイル本体を開かず、Windowsの検索APIで一覧情報だけを確認し、
検索ハンドルをその場で閉じます。共有に書き込みません。共有サーバーへの照会は発生します。
ネットワーク断や親フォルダの削除は原則「確認不可」。通信エラーを「消失」と誤認しないよう
最後に取れた正常な記録を保持します。「消失」は元の名前・場所で見当たらないという意味です。
変更検知に使うのは更新時刻・作成時刻・サイズです。すべてが同じ場合は検出できません。
Windowsの通知設定によりポップアップが出ない場合も、未確認表示は画面と通知領域に残ります。
本番の共有に導入する前に、同じサーバー上のテスト用フォルダで別PCから上書き・削除をご確認ください。

フォルダ監視は、前回の一覧と比較してファイルの追加・更新・消失を通知します。
リネームは旧名の消失＋新名の出現です。空のサブフォルダの作成そのものは通知しません。
１登録あたり５万項目が上限です。リンク先のサブフォルダはたどらず、途中で読み取れない
箇所がある巡回は「確認不可」とします。前回の正常な一覧は残します。

【未読画面と監視対象一覧】
メイン画面には未読の変更だけを表示します。フォルダの配下では変更があったファイルだけが
ツリーに出ます。再帰監視のフォルダは初期状態では折りたたみ、巡回で一覧が更新されても展開状態を保ちます。
一覧の「最新の検知」はツールが変化を検知してからの経過時間です。ファイル自体の更新時刻は「詳細」で確認できます。
サブフォルダを選ぶとその配下、ファイルを選ぶとそのファイルだけを
確認済みにできます。
設定一覧の最終更新はファイル側の時刻です。追加・消失などを検知した時刻は履歴で確認できます。
フォルダ監視は各ディレクトリの一覧情報を取得し、ファイルごとの個別照会は行いません。
【新しい画面の操作】
未読を選んで「詳細 ▾」を押すと、下部に時刻・パス・確認済みになる範囲を表示します。
アイコンでファイルとフォルダを見分けられます。「最終更新者」は、共有先から確認できないので
「取得不可」、フォルダのまとめや消失は「—」と表示します。ファイル所有者で代用しません。
監視先を確認できないときは、画面右下の件数から設定の監視一覧を開けます。
更新ボタン「↻」または Ctrl+R は、監視が有効なときに次の定期巡回を待たずに照会します。
左のツリーは矢印キーで移動できます。Ctrl+, で設定画面を開きます。

【通知一覧の操作】
ダブルクリック・Enter・右クリックの「開く」は同じ動作です。Windows の関連付けでファイルを開き、フォルダはエクスプローラーに渡します。
「動作と表示」の「ファイル・フォルダを開いたら既読にする」は両方に共通です。オンなら開いた対象の範囲を既読にし、オフなら開いても未読のままです。開けなかった場合も未読のままです。
ファイル行の「親フォルダを開く」も既読設定に従います。オンで開けた場合、選んだファイルの表示中の更新だけを既読にします。ほかのファイルや、開く操作中に届いた新しい更新は未読のままです。「コピー」では既読にしません。
通知一覧の右クリック「コピー」または Ctrl+C はファイル・フォルダのコピーです。エクスプローラーで貼り付け先を開き Ctrl+V を押します。元の対象は移動しません。
パス文字列だけをコピーするには「詳細」を開き、パス欄で文字を選択して Ctrl+C を押してください。
監視対象と履歴の一覧は行を選び Ctrl+C で行全体をコピーでき、下部のテキスト欄で一部だけを選択できます。
【通知と履歴】
初期設定では、同じファイルが既に未読なら再通知しません。「動作と表示」→「通知と既読」で
「未読のファイルも更新のたびに通知する」をオンにすると、同じファイルの変更を新たに検知したときも通知します。
どちらの設定でも未読一覧の行はファイルごとに1件で、検知するたび履歴に記録します。
確認済みになった後の新しい変更は再び通知します。未読がある間は通知領域とメイン画面のアイコンに赤いドットが付きます。
「履歴」では、この版で検知した最新1,000件を新しい順に表示します。再通知しなかった変更も記録し、既読にしても履歴は残ります。
変更履歴と未読/既読の状態は cache.sqlite3 に保存し、再起動後も引き継ぎます。
